# Madar Tech

An integrated educational and training platform aimed at bridging academic knowledge with practical application, featuring a dynamic admin dashboard for easy content management.

## Implemented Features

### Main Website (Landing Page)
- Responsive Design: Works seamlessly across all devices (Mobile, Tablet, Desktop) with a custom mobile hamburger menu.
- Visual Animations: Smooth "Fade-in-up" scroll effects using IntersectionObserver, and interactive hover effects on buttons and cards.
- Dark/Light Mode: Toggle between themes while remembering the user's preference.

### Bilingual Support
- Arabic / English: The entire website supports both languages.
- Automatic Direction (RTL/LTR): The page layout and fonts switch automatically when toggling languages (Cairo for Arabic, Inter for English).

### Admin Dashboard
- Access Security: A Login page has been added to prevent unauthorized access to the dashboard.
- Dynamic Content Management: Admins can change texts, colors, and add/remove services and programs directly from the dashboard.
- Local Storage: Changes are saved in LocalStorage and applied instantly to the main website.
- Logout: A dedicated button to safely end the session.

## Tech Stack
- HTML5 & CSS3 (Custom RTL/LTR design).
- JavaScript (Vanilla): For interactions, translations, theme management, and dashboard logic.
- Bootstrap 5 RTL: For page structure.
- Font Awesome & Google Fonts (Cairo & Inter).
- GitHub Copilot: Assisting in accelerating code writing.
